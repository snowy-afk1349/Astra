# ASTRA — Make the Invisible Visible

ArtTech кейсі (Genesis.exe 2026). ASTRA — күн туралы мәтінді, фотоны және әнді көркемдік естелікке айналдыратын атмосфера күнделігі. Әр күн өз көңіл-күйіне сай визуалды тілде жасалады.

## Іске қосу

Ештеңе орнатудың қажеті жоқ.

1. Репозиторийді жүктеңіз немесе клондаңыз.
2. `index.html` файлын браузерде ашыңыз (Chrome немесе Edge ұсынылады).

Қаласаңыз, локалды сервермен де ашуға болады: `python3 -m http.server 8000`, содан кейін `http://localhost:8000`. Қаріптер мен ән ойнатқыштары (Spotify, YouTube, SoundCloud, Apple Music) интернет қажет етеді.

## Қалай қолданады

1. Ашылған экранды басыңыз.
2. «Сценарий» панеліне күн туралы бірнеше сөйлем жазыңыз. Қаласаңыз, ән атауын, ән сілтемесін немесе аудио файлды, 1–3 фотоны қосыңыз. Дайын үлгілер де бар (Күзгі кеш, Түнгі спринт, Жаңбырлы ой).
3. «Визуализациялау» батырмасын басыңыз: постер, палитра, фон және атмосфера күнге сай өзгереді.
4. «Папкаға сақтау» арқылы күнді архивке қосыңыз, PNG ретінде жүктеп алыңыз.

## Мүмкіндіктер

- **Мәтін, фото, музыка → бір постер.** Әр күн 4:5 тірі постер: жоғарыда атау мен күн, ортада фото, төменде мәтін мен ән.
- **Көңіл-күй → көркемдік стиль.** Үш режим: Клод Моне (жылы естелік), Кандинский (қарқынды күн), Ваби-саби (тыныш күн). Режим палитраны, қаріпті, фото сүзгісін және қозғалысты өзгертеді. Пленка түйіршігі барлық күнді бір күнделікке біріктіреді.
- **Талдау сигналдары.** Мәтін (маусым, тәулік, орын, энергия), ән (BPM, мажор/минор: жүктелген аудио файлды талдау немесе сипаттама бойынша) және фото (түс, жылылық) бірге режим мен палитраны анықтайды. Режим таңдалуының себебі экранда түсіндіріледі.
- **Папка атауы.** 3–7 сөзден тұратын атау автоматты жасалады.
- **Музыка.** Сілтемедегі нақты трек ойнайды (Spotify, YouTube, SoundCloud, Apple Music, .mp3). Сілтеме жоқ болса, синтезатор әуені ойнайды.
- **Архив.** Көңіл-күй спектрі, режим бойынша сүзгі, күнді өзгерту және жою, JSON экспорты.
- **Баптаулар.** 15 фон тақырыбы, қозғалыс, түйіршік, мәтін өлшемі, дыбыс деңгейі.

## Claude API (міндетті емес)

Баптаулардағы өріске Anthropic API кілтін енгізсеңіз, папка атауын Claude жазады. Кілт тек ағымдағы қойындыда (`sessionStorage`) сақталады және тек Anthropic-ке жіберіледі, кодта кілт жоқ. Кілтсіз немесе API қолжетімсіз болса, ішкі қозғалтқыш атауды өзі жасайды.

## Шектеулер

- Көңіл-күйді анықтау эвристикаға негізделген, диагноз емес. Режимді таңдауға LLM қатыспайды: ол мәтін, ән және фото сигналдарынан есептеледі. Claude API тек папка атауын жазады.
- Деректер (мәтін, фото, архив) тек осы браузердің `localStorage`-інде сақталады. Аудио файл сақталмайды, тек талдау нәтижесі қалады.
- Жад толса, күн тек ағымдағы сессияда сақталады.

## Технологиялар

HTML, CSS, JavaScript, Canvas, Web Audio API. Сыртқы кітапханалар жоқ.
